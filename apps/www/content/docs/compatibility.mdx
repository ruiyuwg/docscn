---
title: Compatibility
description: The status of every Fumadocs UI module in docscn.
---

This table lists every module that Fumadocs UI ([`@fumadocs/base-ui`](https://github.com/fuma-nama/fumadocs/tree/fumadocs@16.16.2/packages/base-ui) 16.16.2) exports, and its docscn equivalent at `@/components/docs/…`. Supported modules keep Fumadocs UI's exports and main props, apart from the differences listed in [Migrating from Fumadocs UI](/docs/migrating-from-fumadocs-ui#whats-different).

| `fumadocs-ui/…`                                | Status         | Notes                                                                                                       |
| ---------------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| `components/accordion`                         | ✅ Supported   | On shadcn/ui `accordion`                                                                                    |
| `components/banner`                            | ✅ Supported   | Sets `--docs-banner-height` for docscn's layouts                                                            |
| `components/callout`                           | ✅ Supported   | `Callout` on shadcn/ui `alert`                                                                              |
| `components/card`                              | ✅ Supported   | `Cards` / `Card` on shadcn/ui `card`                                                                        |
| `components/codeblock`                         | ✅ Supported   | Code tabs on shadcn/ui `tabs`                                                                               |
| `components/codeblock.rsc`                     | ✅ Supported   | `ServerCodeBlock`                                                                                           |
| `components/dialog/search`                     | ✅ Supported   | On Base UI `Dialog`                                                                                         |
