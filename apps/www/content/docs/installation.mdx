title: Installation
description: Add the docscn registry to your project.
---

docscn supports Next.js projects using shadcn/ui with Base UI.

## Add the registry

Add the `@docscn` registry to your `components.json`:

```bash
pnpm dlx shadcn@latest registry add @docscn=https://docscn.dev/r/{name}.json
```

## Add components

Install components from the registry:

```bash
pnpm dlx shadcn@latest add @docscn/<component>
```
