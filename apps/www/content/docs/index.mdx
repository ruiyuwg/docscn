---
title: Introduction
description: Documentation components for shadcn/ui, built on Fumadocs Core.
---

docscn is a [shadcn/ui](https://ui.shadcn.com) registry of documentation components. Install docs layouts, sidebars, tables of contents, search, and more into your own app with the shadcn CLI.

The components are built on [Fumadocs Core](https://fumadocs.dev/docs/headless) and your existing shadcn/ui primitives, so your docs share the same components and theme as the rest of your project.

docscn is in early development. No components have been published yet.
