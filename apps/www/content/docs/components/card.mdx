---
title: Card
description: Link cards with an icon, title and description.
---

## Installation

```npm
npx shadcn@latest add @docscn/card
```

## Usage

```mdx
<Cards>
  <Card
    title="Getting started"
    href="/docs/getting-started"
    description="Add docs to your project."
  />
  <Card
    title="Fumadocs"
    href="https://fumadocs.dev"
    description="The framework docscn builds on."
  />
</Cards>
```

## Props

<TypeTable
  type={{
    title: {
      description: <>The card's title.</>,
      type: "ReactNode",
      required: true,
    },
    description: {
      description: <>Text below the title.</>,
      type: "ReactNode",
    },
    icon: {
      description: <>An icon above the title.</>,
      type: "ReactNode",
    },
    href: {
      description: <>Makes the card a link.</>,
      type: "string",
    },
    external: {
      description: <>Open the link as an external link.</>,
      type: "boolean",
    },
  }}
/>

Children render below the description. `Cards` lays cards out in two columns, and one on narrow containers. `Card` is built on shadcn/ui `card`.
