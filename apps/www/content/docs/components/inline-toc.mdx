## Installation

```npm
npx shadcn@latest add @docscn/inline-toc
```

## Usage

In MDX, Fumadocs MDX passes the page's headings as `toc`:

```mdx
import { InlineTOC } from "@/components/docs/components/inline-toc";

<InlineTOC items={toc} />
```

Elsewhere, pass `page.data.toc`, or any `TOCItemType[]`. Children replace the "Table of Contents" label.
